# Silero test audio provenance

These are the test WAV fixtures from `emotechlab/silero-rs` at pinned commit
`26a646003cd8532ae2dde424ccdab1b6cdf5d7b0`. Upstream stores them in Git LFS;
this vendored copy keeps the small, exact test payloads in Git so workspace
tests do not depend on Git LFS being installed. `audio-fixtures.json` records each
upstream LFS SHA-256 and byte size. The upstream repository's MIT license and
copyright notice are preserved in `../LICENSE`.

The fixtures are retained unchanged. This note records their source repository
and revision; it does not assert separate authorship or provenance for the
recordings beyond the upstream repository's distribution under its MIT terms.
